Capabilities

Built for speed, focus & expression

🎨

Adaptive Persona System

Switch between Developer, Student, Gamer, Creator, Business, and Entertainment — or generate instant bespoke themes for any topic.

🌐

Real App Favicons & Logos

High-resolution brand logos render in tabs, cards, tiles, and the 3D switcher, bringing instant visual recognition to your workspace.

🗂️

3 Dynamic Tab Layouts

Choose between collapsible Vertical Sidebar, sleek Horizontal Top tabs, or elevated 3D Cards with perspective hover and lift.

⬡

3D Perspective Carousel

Hit Ctrl + Tab to bring up an interactive 3D tab switcher. Move with arrow keys or click directly to focus.

✦

Context-Aware AI Assistant

Built-in AI sidebar that adapts its prompts and suggestion chips based on what you are doing. Keys secured via Electron safeStorage.

⏱️

Productivity Widgets

Built-in Pomodoro focus timers, live clocks, and autosaving quick notes right inside the start page.

Keyboard Shortcuts

Ctrl + TNew Tab
Ctrl + WClose Active Tab
Ctrl + TabOpen 3D Tab Switcher
Ctrl + LFocus Address Bar
Ctrl + RReload Active Tab
Alt + ←Back (Return to Start)
Alt + →Forward
EscClose Modals / Switcher
Get Started

Run Orbit in Minutes

# 1. Clone the repository
git clone https://github.com/<your-username>/orbit.git
cd orbit

# 2. Install dependencies
npm install

# 3. Launch Orbit
npm start
